# Bokhyllan

En stillsam svensk bokrekommendation byggd med Next.js, TypeScript och Tailwind CSS.

## Kör lokalt

```bash
npm install
npm run dev
```

Öppna `http://localhost:3000`.

## Kontroll före demo

```bash
npm run lint
npm run build
```

## Vercel

Projektet kan deployas som en vanlig Next.js-app på Vercel.

- Build command: `npm run build`
- Install command: `npm install`
- Output hanteras av Next.js
- Inga miljövariabler krävs för denna MVP

Affiliate- och payment-kod är mockad och säker. Det finns inga riktiga betalningsnycklar, affiliate-ID:n eller checkout-flöden i projektet.
