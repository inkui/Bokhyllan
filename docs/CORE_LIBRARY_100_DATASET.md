## Data Quality Audit

### Missing ISBNs

**All 100 books.** ISBN13 has been left blank for every entry in this dataset.

**Reason:** ISBNs vary by edition, publisher, language, and region. A Swedish platform may need Swedish-market ISBNs (for Bokus deeplinks via Tradedoubler) that differ from English first-edition ISBNs. Providing ISBNs from memory carries a meaningful risk of single-digit transcription errors, which would silently break affiliate deeplinks. The risk outweighs the convenience.

**Action required:** Manual ISBN lookup for each book, targeting the Swedish-market edition or the most commonly sold current edition on Bokus. See affiliate pipeline requirements in `AFFILIATE_STRATEGY.md`.

## Import Readiness Assessment

### 1. Is this dataset ready for the Library Import Pipeline?

**Partially.** The dataset is structurally complete — all 100 books from the approved proposal are present, correctly categorised, correctly tiered, and carry publication years for 99 of 100 entries. The data is clean: no duplicate titles, no missing required fields beyond ISBN (which was intentionally deferred).

The dataset is **not ready for automated import** because no ISBNs are present. The pipeline in `LIBRARY_IMPORT_PIPELINE.md` requires an ISBN to fetch cover images, trigger the Bokus deeplink via Tradedoubler, and resolve bibliographic metadata. Without ISBNs, the pipeline can accept the records as BookCandidate entries but cannot advance them past the Metadata stage.

**Recommended next step:** Manual ISBN lookup for all 100 books, prioritising the 11 books flagged for manual verification above. Target the Swedish-market Bokus edition where it exists; fall back to the current primary English-language edition.

---

### 2. What metadata gaps remain?

**ISBN13 — all 100 books.** Primary gap. Blocks Metadata stage.

**Publication year — 1 book** (Meditations / Marcus Aurelius). Secondary gap; requires a policy decision about how Bokhyllan records ancient texts.

**Target edition/translation — 11 books** flagged above. These require an editorial decision before ISBN lookup can proceed. The decision is about which edition or translation Bokhyllan recommends, not just which ISBN to record.

**Author display format — 1 book** (Good Omens: Pratchett & Gaiman). Requires a decision on whether the author field is a single string ("Terry Pratchett & Neil Gaiman"), two separate records, or another format.

**Original-language title — all Swedish_Voices books and all International_Voices books.** The pipeline may need both the canonical Bokhyllan display title and the original-language title for metadata matching. This field is not present in the current dataset.

**Cover image — all 100 books.** Not included in this dataset; expected to be fetched by the pipeline from the ISBN. Blocked on ISBN completion.

---

### 3. Which books are likely to require manual verification?

**High manual effort — 11 books** (flagged in Data Quality Audit):

Meditations, The Master and Margarita, The Diving Bell and the Butterfly, The Guernsey Literary and Potato Peel Pie Society, The Death of Ivan Ilyich, Good Omens, My Brilliant Friend, If This Is a Man, Letters to a Young Poet, The Book of Disquiet, Solaris.

**Moderate manual effort — all translated works (~20 books):** Swedish-market ISBNs for translated works frequently differ from the English first-edition ISBN and may not appear in general ISBN databases. Requires direct lookup on Bokus.

**Standard effort — remaining ~69 books:** Single-edition English works with stable ISBNs. Manual lookup expected to be straightforward.
